# 全球市場日報生成器

## 功能說明

自動搜集全球各區域指定主題的新聞，並整合成深度分析報告。

## 涵蓋區域

1. 北美（North America）
2. 南美（South America）
3. 中國（China）
4. 歐洲（Europe）
5. 日本（Japan）
6. 韓國（South Korea）
7. 台灣（Taiwan）
8. 中東（Middle East）
9. 東南亞（Southeast Asia）
10. 印度（India）

## 執行步驟

### 步驟 1：收集使用者輸入

**必須先向使用者詢問以下資訊**：

1. **日期**
```
   請問要搜集哪一天的新聞？
   格式：YYYY-MM-DD（例如：2025-01-11）
   或直接說「今天」、「昨天」
```

2. **主題**
```
   請問要搜集哪些主題的新聞？
   
   常見主題範例：
   - FWA（固定無線接入）
   - Broadband（寬頻）
   - 5G
   - Fiber（光纖）
   - Satellite Internet（衛星網路）
   - DOCSIS
   - WiFi 7
   
   可以輸入多個主題，用逗號分隔
   例如：FWA, Broadband
```

3. **確認資訊**
```
   確認您的需求：
   - 日期：[使用者輸入的日期]
   - 主題：[使用者輸入的主題]
   - 區域：全球 10 個區域
   
   是否正確？(是/否)
   如需修改，請告訴我要修改哪一項。
```

**只有在使用者確認後，才開始執行搜尋。**

### 步驟 4：深度整合分析

**不要只是翻譯或列出標題**！

對每個區域，需要：

1. **閱讀並理解**所有新聞內容
2. **提取關鍵資訊**：
   - 技術發展（新技術、新產品、新標準）
   - 商業動態（併購、合作、市場策略）
   - 政策法規（監管變化、頻譜分配）
   - 市場趨勢（用戶增長、價格變化、競爭格局）
3. **分析脈絡**：
   - 這些新聞反映了什麼趨勢？
   - 背後的技術或商業邏輯是什麼？
   - 對產業有什麼影響？
4. **整合成文**：
   - 約 700 字的繁體中文報告
   - 有邏輯結構
   - 有深度見解

**分析框架**：

每個區域的深度日報應包含：

- **開場**（50-100字）：該區域當日最重要的發展或趨勢
- **技術動態**（150-200字）：新技術、新產品、技術標準的進展
- **商業脈絡**（150-200字）：企業策略、併購合作、市場競爭
- **政策與監管**（100-150字）：政策變化、監管動向、頻譜議題
- **市場趨勢**（100-150字）：用戶數據、價格變化、未來展望
- **關鍵洞察**（50-100字）：總結性的觀察和影響評估

## 品質要求

### ✅ 必須做到：

1. **使用者輸入驗證**
   - 確保日期格式正確
   - 確保主題明確
   - 顯示確認訊息
   - 允許修改

2. **語言正確性**
   - 用當地語言搜尋當地市場
   - 最終輸出全部用繁體中文
   - 翻譯準確無誤

3. **日期準確性**
   - 所有新聞必須是使用者指定日期
   - 不可使用過期新聞
   - 在分析前先驗證日期
   - 明確標註日期不符的情況

4. **數量要求**
   - 每區域目標至少 10 則
   - 不足時必須通知並詢問處理方式
   - 在報告中明確標註數量不足的區域

5. **來源可追溯**
   - 每則新聞都要有完整 URL 連結
   - 連結必須可點擊
   - 標註來源網站名稱
   - 按區域列出所有來源

6. **深度分析**
   - 不只是翻譯標題
   - 要整合多則新聞的資訊
   - 要分析背後的技術與商業脈絡
   - 每個區域約 700 字（可彈性調整）
   - 使用結構化的分析框架

### ❌ 禁止事項：

1. ❌ 不可在未收集使用者輸入前就開始搜尋
2. ❌ 不可用英文或其他語言搜尋非英語區域（除非該區域主要使用英文）
3. ❌ 不可使用與使用者指定日期不符的新聞
4. ❌ 不可只列標題而不做深度分析
5. ❌ 不可省略任何來源連結
6. ❌ 不可在數量不足時不通知使用者
7. ❌ 不可自行補充舊新聞充數
8. ❌ 不可跳過任何區域（除非使用者同意）

## 注意事項

### 1. 執行時間預期

- 單一區域搜尋：約 30-60 秒
- 全部 10 個區域：約 10-15 分鐘
- 分析整合：約 5-10 分鐘
- **總計預計時間：20-30 分鐘**

### 2. Token 使用量

這個 Skill 會使用大量 tokens，因為：
- 需要進行 10 次以上的 web_search
- 需要讀取和分析大量新聞內容
- 需要產生約 7000+ 字的深度分析

建議使用 Claude Max 方案以獲得充足的使用額度。

### 3. 時區考量

- 如果在早晨執行（如台灣時間早上 8 點）
- 某些區域可能還沒有當日新聞
- 建議在下午或晚上執行以獲得更完整的新聞

### 4. 搜尋策略優化

如果某個區域反覆搜尋不到足夠新聞：
- 可能該市場確實新聞較少
- 可以調整關鍵字或擴大時間範圍
- 或接受較少數量但確保品質

### 5. 語言翻譯準確性

### 1. 執行時間預期

- 單一區域搜尋：約 30-60 秒
- 全部 10 個區域：約 10-15 分鐘
- 分析整合：約 5-10 分鐘
- **總計預計時間：20-30 分鐘**

### 2. Token 使用量

這個 Skill 會使用大量 tokens，因為：
- 需要進行 10 次以上的 web_search
- 需要讀取和分析大量新聞內容
- 需要產生約 7000+ 字的深度分析

建議使用 Claude Max 方案以獲得充足的使用額度。

### 3. 時區考量

- 如果在早晨執行（如台灣時間早上 8 點）
- 某些區域可能還沒有當日新聞
- 建議在下午或晚上執行以獲得更完整的新聞

### 4. 搜尋策略優化

如果某個區域反覆搜尋不到足夠新聞：
- 可能該市場確實新聞較少
- 可以調整關鍵字或擴大時間範圍
- 或接受較少數量但確保品質

### 5. 語言翻譯準確性

- 主題翻譯對照表會持續更新
- 如發現更好的翻譯請告知
- 某些技術術語在不同市場可能有不同用法

## 持續改進建議

使用後可以收集以下反饋來優化 Skill：

1. **搜尋效果**：哪些區域的搜尋關鍵字最有效？
2. **來源品質**：哪些新聞來源最可靠？
3. **分析深度**：700 字是否足夠？是否需要調整？
4. **格式調整**：報告格式是否清晰易讀？
5. **互動流程**：輸入流程是否順暢？

可以將這些反饋整理後更新到 Skill 中。
