# 檔案整理器

## 功能說明

這個 Skill 幫助使用者整理雜亂的資料夾，將檔案依照類型分類到不同的子資料夾中。

## 指令

當使用者要求整理檔案時，請按照以下步驟：

1. **詢問目標資料夾**
   - 問使用者想整理哪個資料夾
   - 確認資料夾路徑是否正確

2. **掃描檔案**
   - **只處理指定資料夾根目錄下的檔案**
   - **忽略所有子資料夾內的檔案**（子資料夾內的檔案已經分類過了，不需要移動）
   - 列出符合條件的檔案
   - 顯示檔案數量和類型分布

3. **建立分類資料夾**
   依照檔案類型建立以下子資料夾：
   - Documents/ - 文件檔案（.pdf, .doc, .docx, .txt, .md）
   - Images/ - 圖片檔案（.jpg, .jpeg, .png, .gif, .svg）
   - Videos/ - 影片檔案（.mp4, .mov, .avi, .mkv）
   - Archives/ - 壓縮檔（.zip, .rar, .7z, .tar.gz）
   - Code/ - 程式碼檔案（.py, .js, .java, .cpp, .html, .css）
   - Others/ - 其他檔案

4. **移動檔案**
   - **只移動根目錄下的檔案，不進入子資料夾**
   - 將每個檔案移動到對應的分類資料夾
   - 如果遇到同名檔案，詢問使用者如何處理
   - 移動前先顯示計畫，詢問使用者是否確認

5. **回報結果**
   - 顯示移動了多少檔案到各個分類
   - 顯示有多少子資料夾被保留（未處理）
   - 列出整理結果摘要

## 重要規則

- ⚠️ **只整理根目錄的檔案**：如果檔案在任何子資料夾中（包括現有的分類資料夾），就跳過不處理
- ⚠️ **保留所有子資料夾**：不移動、不刪除任何資料夾
- ⚠️ **絕對不要刪除任何檔案**
- ⚠️ **移動前必須先確認使用者同意**
- ⚠️ **保持原始檔案的完整性**

## 掃描範例
```
目標資料夾：~/Downloads/

掃描結果：
根目錄檔案（需要整理）：
  - report.pdf
  - photo.jpg
  - video.mp4
  
子資料夾（保持原樣，不處理）：
  - Documents/ (內含 3 個檔案)
  - Old_Files/ (內含 10 個檔案)
  - Work/ (內含 5 個資料夾)

將整理 3 個檔案，保留 3 個子資料夾。
```

## 使用範例

**範例 1：基本使用**

使用者：「我的下載資料夾很亂，幫我整理一下」

助手會：
1. 詢問要整理的資料夾路徑
2. 只掃描根目錄的檔案（忽略子資料夾）
3. 顯示將要整理的檔案清單
4. 提出整理計畫
5. 等待確認後執行
6. 回報整理結果（例如：移動了 15 個檔案，保留了 3 個子資料夾）

**範例 2：已有部分分類的資料夾**
```
資料夾結構：
~/messy-folder/
  ├── file1.pdf          ← 會被移動到 Documents/
  ├── file2.jpg          ← 會被移動到 Images/
  ├── Documents/         ← 保留不動
  │   └── old1.pdf       ← 不處理
  └── Photos/            ← 保留不動
      ├── pic1.jpg       ← 不處理
      └── pic2.png       ← 不處理

結果：
只有 file1.pdf 和 file2.jpg 會被移動
Documents/ 和 Photos/ 資料夾保持原樣
```
